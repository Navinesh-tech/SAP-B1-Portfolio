# Crystal Reports

Print layouts built in SAP Crystal Reports for SAP Business One. Each folder has the report screenshot, the SQL query and a short Readme.

| Folder | Report |
|---|---|
| Delivery | Delivery Challan |
| AP_DebitNote | Debit Note to suppliers |
| AR_CreditNote | Credit Note to customers |
| ExportInvoice | Export Invoice (USD / INR) |
